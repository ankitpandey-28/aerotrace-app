# AeroTrace Roadmap

This roadmap reflects the current progress and next milestones for AeroTrace. It is maintained alongside the codebase and updated as features ship.

## Completed (Implemented)
- Live GPS journey tracking
- Real-time route visualization
- Journey Summary page
- Life Map visualization
- Memory capture (photos + notes)
- Local storage persistence
- Interactive maps and timeline navigation
- Memories Reel (new): cinematic journey reels grouped by month — story-first detail view

## Near-term (In Progress / Next Release)
- Data export/import (GPX/JSON)
- Improved journey statistics (elevation, pace)
- Better mobile layout & PWA support
- Simple unit + integration tests

## Planned (Q3–Q4)
- Backend integration: secure API for sync and storage
- User accounts & authentication
- Cloud sync and multi-device continuity
- AI-generated journey stories & photo-based memory summaries
- Community sharing, curated discovery feeds

## Visionary (Future)
- Premium sync/backups and AI story exports
- Curated community discovery feeds and local creator tools
- Native mobile companion apps with offline-first sync
